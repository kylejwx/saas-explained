# Design Preferences

This document records durable design choices for SaaS Explained. Add new preferences here when they should guide later site work.

## Current preferences

- Preserve the existing homepage's main interface and visual layout unless a future change explicitly calls for revisiting it.
- Add new homepage content below the existing layout, using the established section pattern: an H2 heading followed by concise explanatory paragraphs.
- Keep the roadmap easy to discover through both a dedicated top-navigation link and a homepage section.
- Place VitePress's "On this page" outline on the left side of documentation pages.

## Future preferences

Record future decisions with the preference, the reason for it, and any page or component it affects. Keep this document focused on durable design direction rather than one-off implementation details.
